# Sequelize + SQLite: Первая модель

Консольное приложение на Node.js с использованием ORM Sequelize и базы данных SQLite.

## Предметная область

Таблица **Cars** (Автомобили) содержит информацию об автомобилях в автосалоне.

## Поля таблицы

| Поле | Тип | Описание |
|---|---|---|
| `id` | INTEGER | Автоматически добавляется Sequelize (первичный ключ) |
| `brand` | STRING | Марка автомобиля (обязательное) |
| `model` | STRING | Модель (обязательное) |
| `year` | INTEGER | Год выпуска |
| `price` | FLOAT | Цена в рублях |
| `isAvailable` | BOOLEAN | Доступен ли для продажи |
